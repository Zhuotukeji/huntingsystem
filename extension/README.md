# 觅才 BOSS 寻访助手

1. 在系统“数据源与设置”中设置至少 10 位的插件访问码。
2. 打开 `chrome://extensions`，启用开发者模式。
3. 选择“加载已解压的扩展程序”，指向本目录。
4. 启动本地系统后，点击扩展图标，在侧边栏使用内部邮箱和访问码登录。

插件没有 content script，不读取 BOSS DOM、Cookie 或账号信息，不自动翻页、打开候选人或发送消息。`分析当前可见结果` 只会在 HR 点击后截取当前可见标签页，截图发送到内部后端分析且不落盘。生产环境若使用非本机后端，需要把明确的后端域名加入 `manifest.json` 的 `host_permissions`。

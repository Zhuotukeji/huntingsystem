# 觅才 BOSS 寻访助手 V0.2

## 安装

1. 启动觅才后台，推荐使用 `pnpm dev --port 3010`；插件会先检测 3010，再检测 3000。
2. 在后台“数据源与设置”中配置至少 10 位的插件访问码；使用截图前还需配置 Sub2API 并启用截图分析。
3. 打开 `chrome://extensions`，启用开发者模式。
4. 选择“加载已解压的扩展程序”，指向仓库的 `extension/` 目录，或指向分发 ZIP 的解压目录。
5. 点击扩展图标，在侧边栏使用工作邮箱和插件访问码登录。

## 日常闭环

- 领取 AI 生成的搜索任务，复制关键词并手工打开 BOSS。
- HR 主动点击后，插件只截取当前可见的 BOSS 页面；发送到 Sub2API 前会再次确认。
- 评分结果同时显示证据和未知项，招呼语只生成可复制草稿，不自动发送。
- 回填结果人数、符合画像人数和有效沟通人数，系统据此小步更新搜索权重。
- 可导入 PDF、DOCX、TXT 或粘贴文本；必须选择来源、填写处理依据并勾选授权确认。非重复简历会自动创建增量学习队列。

## 合成验收

插件设置中可打开内置的合成 BOSS 样式页面。该页面不含真实候选人数据，可用于验证可见页截图、Sub2API 识别、评分证据和招呼语草稿链路。

## 权限边界

插件没有 content script，不读取 BOSS DOM、Cookie、账号、密码或验证码，不自动搜索、滚动、翻页、打开候选人或发送消息。`activeTab` 仅用于 HR 主动触发的当前可见页截图；截图不在后端文件、数据库或日志中持久化。当前分发版只允许访问 `localhost` 和 `127.0.0.1` 后端。

## 检查与打包

```bash
pnpm extension:assets
pnpm extension:check
pnpm extension:pack
```

打包产物为 `artifacts/hunting-extension-v0.2.0.zip`，SHA-256 位于同名 `.sha256` 文件。
